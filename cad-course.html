00先说清楚：这门课怎么学才有效

CAD 不是知识课，是手上功夫。看懂了不等于会画，会画了不等于画得快。所以这份路线的结构是：一节视频 → 一段练习 → 一件必须交出来的东西。

1. 每集视频，看完必须关掉重画一遍 第一遍跟着画，第二遍关掉视频自己从零画。关掉还能画出来，才算学过。这一条比看多少集都重要。
2. 只用键盘，不点工具栏 从头就养成输命令的习惯（L、C、TR…）。点按钮画图的人，永远快不起来。
3. 每章交一个文件，不合格就重画 任务下面列的是验收标准，不是建议。尺寸差一点、图层乱一点，都不算过。
4. 卡住先查 F1，再查 GitHub CAD 里按 F1 是 Autodesk 官方帮助，比任何教程都准。画不出来的图，附录 A 有 30 天抄图表，按当天的章节进度取图。

03第 1 章 · 界面、坐标系、直线

目标：能在空白图里，用键盘准确画出指定长度的水平线和垂直线，不再靠鼠标瞎拖。

1

把坐标系装进脑子

入门 01–02 集 · 约 11 分钟 · 练习 2.5 小时

视频（新版集号）
  1. 入门 01 界面设置及基础操作 5:49
  2. 入门 02 直线绘图工具 5:40
  3. 高级 12 坐标 选看，第 1 章会用到

第 1 集里有三件事必须做：右下角齿轮切到「草图与注释」工作空间；OP 打开选项 → 显示 → 十字光标拉到 100；记住 Z E 看全图和 P 平移。

概念自测
画完图，屏幕上什么都没有了，一步找回？
Z 空格 E 空格（范围缩放）。图形跑到视野外时，这是最快的救回方法，比滚轮乱滚靠谱。
F8 和 F3 分别管什么？
F8 = 正交，光标只能走水平/垂直；F3 = 对象捕捉，靠近端点、中点、圆心会自动吸附。画图时这两个几乎全程开着。
输入 100,50 和 @100,50 有什么区别？
100,50 = 绝对坐标，指图纸上坐标为 (100,50) 的那个点；@100,50 = 相对坐标，指「从上一个点往右 100、往上 50」。实际画图 95% 用相对坐标。
从当前点画一条长 120、与水平成 30° 的斜线，怎么输？
@120<30。格式是「@长度<角度」，角度逆时针为正。这类叫极坐标，画斜线和圆弧时天天用。
画线时提示「指定下一点或 [闭合(C)/放弃(U)]」，想撤掉刚才那一段？
输 U 空格，退一段；想整体结束按空格或 Esc。注意 U 是退一段，Esc 是整条命令退出但已画的线还在。
为什么明明开了对象捕捉，还是抓到了旁边的点？
因为图太密、捕捉框抓到了最近的那个标记。解决办法：放大到能看清再点，或者临时按 F3 关掉捕捉手动点。这是新手最常犯的「画出来差 0.5 mm」的根源。
任务 T1 · 六级台阶剖面 作业/01-阶梯剖面.dwg

画一个楼梯的侧面剖切轮廓：每级踏面宽 300、踢面高 150，共 6 级，底部封口成闭合轮廓。整张图全部用 L 命令 + 相对坐标完成，全程 F8 正交，不许点工具栏。

  1. 新建图纸，L 空格，起点输 0,0（绝对坐标，定在地面上）。
  2. 向上 @0,150，向右 @300,0。这两步是一级台阶。
  3. 把上一步的两句再重复 5 遍，一共 6 级，最后应该停在 (1800, 900)。
  4. 向下封口 @0,-900，向左回起点 @-1800,0，空格结束。
  5. 自检：ID 空格点最右上那个角，看命令行报的坐标是不是 1800,900。
大概率会踩的坑
  • 忘打 @，线一下飞到 (300,0)，图看着是散的一堆短线——这是坐标系没进脑子，重画一遍。
  • 数量数错，画成 5 级或 7 级。老师改图只看总尺寸，1800 对不上就是错。

04第 2 章 · 圆、圆弧、多段线、多边形

目标：掌握「圆的 6 种画法」里最常用的 4 种，学会用对象捕捉把图形准确挂到已有图形上——这是 CAD 里最关键的手感。

从“点线”升级到“几何关系”

入门 03–06 集 · 约 24 分钟 · 练习 3.5 小时

视频
  1. 入门 03 圆 8:53
  2. 入门 04 圆弧 4:29
  3. 入门 05 多段线 6:20
  4. 入门 06 多边形 4:13
概念自测
已知一条线的两个端点，要以它们为直径画圆，用哪个选项？
C → 输 2P → 点两个端点。同理 3P 是过圆周上任意三点（画外接圆用）。
要画一个同时和两条直线相切的圆，命令怎么走？
C 空格 → 输 T（切点、切点、半径）→ 在两条线上各点一下 → 输半径。这是画过渡圆弧、倒圆最常用的方式，比算坐标快一百倍。
画一个内接于半径 80 的圆的正五边形？
POL → 输 5 → 点圆心 → 输 I（内接）→ 80。I 是顶点在圆上，C 是边与圆相切，画螺母用 C，画星形用 I。
多段线（PL）和普通直线（L）最本质的区别？
多段线画的整条是一个对象，且可以带宽度、可以直接变成圆弧段；直线画的每一段都是独立对象。做轮廓、做填充边界、算面积，都用多段线。
已经用 L 画了一堆首尾相连的线，怎么合成一条多段线？
PE 空格 → M → 框选全部 → 空格 → Y → 选「合并」→ 空格。这个命令在第 4 章算面积时要用。
圆弧用「起点-端点-半径」时，凸向哪边由什么决定？
由两点的先后顺序决定，圆弧总是从起点逆时针走向端点。画反了就把两个点换个顺序点，别去调半径。
任务 T2 · 圆形徽标 作业/02-圆形徽标.dwg

画一个直径 240 的徽标：外圆 φ240、内圆 φ200 同心，中间一个内接于 R80 圆的正五边形，五边形顶点两两连线成五角星，外圈加三段装饰弧。这一张练的是「把新图形挂到旧图形上」。

  1. C 空格，圆心输 0,0，半径 120；再 C 空格，圆心直接把光标放到刚画的圆上、等出现「圆心」标记再点，半径 100。两个圆心必须重合。
  2. POL 空格 → 5 → 圆心同上用捕捉 → I → 80。五边形顶点会落在 R80 上。
  3. L 空格，从五边形一个顶点连到隔一个的顶点（用「端点」捕捉），连 5 条，成一个五角星。会多出 5 个交叉点，这是对的。
  4. A（圆弧）→ 起点落在外圆、端点落在内圆，输半径 110，做一段装饰弧。同样操作再来两次，三段弧分别放在 0°、120°、240° 三个方向（换起点位置就行，这一章还不要求复制）。
  5. PL 空格 → 输 W → 起点宽 6 终点宽 6 → 沿五角星一条边画一段带宽度的小飘带，体会宽多段线。
大概率会踩的坑
  • 第二、三个圆的圆心靠「看着差不多」点上去 → 差 0.3 mm，肉眼看不出来，但 DIST 一量就露。必须等捕捉标记出现再点。
  • 五角星连成「相邻顶点」了，画出来是正五边形。要连隔一个的顶点。

概念自测
拉伸（S）和移动（M）本质区别在哪？
M 是整个搬走，形状不变；S 是把框住的那部分端点拉走，形状会变。而且 S 必须用交叉窗口（从右下往左上框）选择，只包住一半的对象才会被拉伸。甲方案改尺寸最常用的就是 S。
一个图形已经有 17° 的斜角，现在想让它是 0°（水平），用旋转怎么一步到位？
RO → 选对象 → 定基点 → 输 R（参照）→ 点斜线上两点 → 再点水平方向一点。不查角度、不心算，这是旋转最实用的用法。
对齐（AL）命令最后问「是否基于对齐点缩放对象」，选 Y 和 N 差什么？
N 只旋转+平移让两个点对上；Y 还会把对象缩放，使第二组点也重合。要把一个块贴到一段长度不同的墙上，就用 Y。
镜像完发现原对象还在，怎么只留镜像出来的那个？
镜像时命令行问「是否删除源对象」，输 Y 就删掉原图。忘了输也不怕：事后选中原图删掉即可。
缩放（SC）输入 1.5 是放大还是缩小？
放大 1.5 倍。比例因子大于 1 放大、小于 1 缩小（输 0.5 = 缩一半）。缩放会连标注尺寸一起变，注意。
复制（CO）时想一次复制一串等距的对象，怎么做最省事？
CO 选对象定基点后，连续输多个位移点（如 @500,0 回车 @500,0 回车…），一次命令复制一排。再快一点就用第 5 章的阵列。
这套课没讲矩形（REC）和偏移（O），这两个该怎么用？
REC：空格 → 点第一角点 → 输 @宽,高，带圆角先输 F 设半径；矩形本质是一条闭合多段线。O 偏移：空格 → 输距离 → 选对象 → 点哪边就往哪边偏移，画墙厚、画等距线比复制快。这两个命令后面几章都会用到，两分钟就能上手。
任务 T3 · 窗格立面 作业/03-窗格立面.dwg

画一扇 3×3 的窗：每格 500×500，九格贴合成 1500×1500 的整体，然后把整扇窗绕左下角旋转 30°，再用镜像做出对开的两扇，两扇之间留 20 的缝。

  1. 用 L 从 0,0 画一个 500×500 的方框（@500,0 → @0,500 → @-500,0 → C 闭合）。
  2. CO 选它 → 基点随便定在左下角 → 连续给 @500,0、@1000,0 → 空格。得到一个横排。
  3. 再 CO 框选这三个 → 连续给 @0,500、@0,1000 → 空格。九格齐了。
  4. RO 全选 → 基点定在整扇窗左下角 → 输 30。
  5. MI 全选 → 镜像线竖直画在右侧 20 处（先在旁边画一条辅助竖线，用偏移 O 或 L 画）→ 镜像完保留原对象。
大概率会踩的坑
  • 复制时基点没定在图形的角上，第二排就对不齐。基点永远优先选图形的角点或圆心。
  • 旋转前没全选，只转了一格。

剪刀是 CAD 的灵魂

入门 11–13 集 · 约 11 分钟 · 练习 3 小时

视频
  1. 入门 11 修剪和延伸 4:20
  2. 入门 12 圆角和倒角 3:39
  3. 入门 13 曲线和曲线连接 2:57
概念自测
修剪（TR）最快的用法是什么？
TR 空格 空格——两下空格表示「全图都当边界」，然后你想剪哪段点哪段，点哪剪哪。
圆角（F）半径设成 0，会有什么效果？
两条线会直接延伸/修剪到相交成尖角。这是 CAD 里最快让两条线「正确相交」的办法，比先延伸再修剪快得多。
倒角（CHA）和圆角（F）差别在哪？
倒角切的是斜直线（要设两个距离 D），圆角切的是圆弧（要设半径 R）。机械件去毛刺用倒角，铸造件过渡用圆角。
合并（JOIN）能连什么、不能连什么？
能把共线或首尾相接的同类对象连成一个整体；中间有断口、不共线的连不上。连成闭合多段线之后，AREA 才能正常算面积。
点了半天剪不掉，一般是什么原因？
三种：① 剪的那段没跟边界真的相交（差一点点，放大看）；② 对象被锁定图层了；③ 你想剪的是块内部的线，得先炸开（X）。
任务 T4 · 开口扳手 作业/04-开口扳手.dwg

画一把开口扳手的完整外轮廓：头部圆 φ44、尾部圆 φ30，两圆心相距 160，用两条外公切线连起来，头部开一个 18 宽的开口，开口根部倒 R6 圆角，最后合成一条闭合多段线。

  1. C 圆心 0,0 半径 22；再 C 圆心 160,0 半径 15。
  2. 画切线：L 空格 → 按住 Shift 右键 → 选「切点」→ 点第一个圆上半部 → 再 Shift+右键「切点」→ 点第二个圆上半部。下半部同样再来一条。

概念自测
环形阵列必须指定哪三样东西？
中心点、项目数、填充角度（360° 就是绕一整圈）。另外注意「关联」开关：开着，改一个全变，改数量自动增删。
阵列开着「关联」和关着有什么实际区别？
关联 = 整组是一个对象，改项目数全组跟着变；不关联 = 炸成一堆独立对象，改一个只改一个。做重复构件要关联，做一次性的排布可以不关联。
几何约束和标注约束，分别管什么？
几何约束管关系（水平、垂直、相等、相切、同心）；标注约束管数值（宽 100、角 30°）。先用几何约束定形状，再用标注约束定大小，这个顺序反了会过约束。
图形突然变红、怎么拖都不动，是什么情况？
一般为过约束：同一件事被两处约束同时规定死了（比如既相等又各标了不同尺寸）。删掉其中一条约束就好。
把标注约束的 100 改成 80，图形没反应，为什么？
多半是这个尺寸没被真正约束住（约束图标是灰的/或图形被「固定」约束锁死）。要看到图形跟着缩，必须有能动的自由度。

概念自测
0 层特殊在哪？
不能删、不能改名，而且画在 0 层上的线，一旦被做成块，颜色会跟着插入的图层走。所以正规做法：0 层只用来放块，日常图形一律分到自己的图层。
特性里的 ByLayer 是什么意思？
「随层」——颜色、线型、线宽全都跟着它所在的图层设置走。正确做法是画图时全部 ByLayer，想改颜色就改图层，不要单个对象去改颜色。
图层「关闭」和「冻结」有什么区别？
关闭只是看不见，还参与运算；冻结完全不参与重生成和打印预演，大图卡的时候冻结比关闭有效得多。打印不想出现的图层，用冻结。
中心线设成 DASHED 线型，画出来还是一根实线，为什么？
线型比例太小，虚线密到看不见。输 LTSCALE，把比例调大（比如 10 或 20），或者改那个图层的「线型比例」。这是新手 100% 会遇到的。
B 和 W 都是做块，区别？
B = 内部块，只存在当前这张图里；W = 写块，单独存成一个 .dwg 文件，可以插到任何图里。标题栏、标准件做成 W。
普通块和属性块差在哪？标题栏为什么要用属性块？
普通块里的字是死的，改一次要进块编辑器；属性块里的字是可填的字段（用 ATT 定义的），插入时弹框让你填，双击还能改，将来还能用「数据提取」把几十张图的图名一次导成表格。标题栏、图框、标准件这类「结构固定、内容每张不同」的东西，标准做法都是属性块。
改了块里的一条线，图里所有同名块都变了，靠什么实现的？
因为块是引用，改的是「块定义」。用 BEDIT（块编辑器）或双击块进入编辑，改一次全部引用同步更新——这才是块的真正价值。

概念自测
标两点之间的水平/垂直距离，用哪个命令？
DLI 线性标注。斜线方向的距离用 DAL（对齐标注），半径 DRA，直径 DDI，角度 DAN，连续标注 DCO。
标注文字太小/太大，改哪里才对？
改标注样式（D → 文字高度），不要一个一个去改标注对象。图太小就调「调整 → 使用全局比例」，一处改全部跟着变。
打印预览是空白的，最可能的原因？
① 打印范围选成了「显示」而图在别处；② 图层的「打印」列被关掉了；③ 打印样式表里颜色映射成白色。按这个顺序查。
要输出 PDF，打印机选哪个？
DWG To PDF.pc3。图纸尺寸选 A3，打印区域选「窗口」框住图框，勾上「居中打印」和「打印对象线宽」，比例选 1:1。
填充（H）跟着边界改了不跟着变，为什么？
填充的「关联」没开。重建的时候勾上关联，边界一动填充自动重算。另外填充不显示，通常是「填充显示」FILLMODE 被关了。
尺寸线压住了图形，怎么调？
选中标注，拖夹点挪位置；或者用 MLEADER 引线把数字引到图外。别用直线去遮挡，会留一堆碎线。
单行文字（DT）和多行文字（MT）该用哪个？
短标签用 DT，成段的话用 MT。DT 每行是一个独立对象，写好几行就有几个对象，适合「A-A」「R6」这种；MT 一个对象里能放多段、能单独加粗某几个字、能堆叠公差，技术要求必须用它。改一整段话，MT 是双击一次的事，DT 得挨个改。
标题栏用属性块还是表格？
标题栏用属性块，明细表用表格。标题栏是每张图都要、格子固定、只需改几个字——做成属性块（中级 07 的「文字块」+ 第 6 章的 TITLE-A3），插入时弹框填，双击还能改。明细表（零件清单）行数会变，得用 TABLE，加行删行不用重画。
模型空间画好了，为什么还要进布局？
模型空间是按真实尺寸 1:1 画的图，布局空间是那张纸。出图比例、图框、标题栏放在布局里，视口负责把模型「摆」到纸上。这样同一张图要出 A3 和 A1，不用改图形，只改视口比例。高级 13–14 两集讲的就是这件事。

2. 超时就算没画完25 分钟闹钟响了还差一大截，直接停，记下卡在哪个命令，第二天重画同一张。硬撑到 1 小时是无效练习。
3. 存成 作业/练/p01.dwg一张一个文件，编号跟表里的天数一致。往后想回头看自己第 5 天长什么样，翻得到。

验收清单靠肉眼容易骗自己。这个脚本会把每一条验收直接判成 PASS / FAIL，失败项还给一句「该怎么改」——像下面这样：

用法（三步，不用装任何东西）：① CAD 里 另存为 → 文件类型选 AutoCAD 2010 DXF (*.dxf)，存进 作业/；② 打开命令行，进到 D:\复习程序；③ 跑：

它判不了「好不好看」，也判不了那张 PDF 的线宽——这两件事只能自己打开看。
